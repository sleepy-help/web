## FAQ

**Q: Do I need to be available full-time?**
A: No. We're async-first. Contribute when you can. Communicate clearly.

**Q: Can I contribute part-time while learning?**
A: Yes! We value growth. Start small, build trust, take on more.

**Q: What if I don't match a role exactly but want to help?**
A: Tell us what you're great at. We'll find a fit.

**Q: Is this remote?**
A: 100% remote. Work from anywhere.

**Q: What's the time commitment?**
A: Flexible. 5-10 hours/week for part-time, 20-40 for core team. You decide.

**Q: When do you expect to hire?**
A: Now for high-priority roles (marked 🟢). Future roles (🟡) when we reach that phase.

**Q: Can I switch roles later?**
A: Absolutely. Learn new domains, grow with the project.
